# 15 — Implementation Plan (Tennis)
**Phase 1 MVP (wks 1–5):** player tracking + court calibration + scoring engine with
manual/assisted point entry + live scoreboard.
**Phase 2 Beta (wks 6–12):** TrackNet ball tracking + bounce detection + auto IN/OUT
(single cam, with close-call review) + serve speed + match stats.
**Phase 3 Production (wks 13–24):** multi-camera sync + triangulation toward 95%+ calls,
highlights, coach analytics, accuracy validation vs human judges, hardening.
