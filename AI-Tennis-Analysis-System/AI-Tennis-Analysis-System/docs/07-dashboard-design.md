# 07 — Dashboard Design (Tennis)
**Spectator:** big live scoreboard (sets/games/points, server), ball-tracking
visualization (court overlay + trajectory), live stats (rally length, serve speed),
line-call ticker (close calls flagged), instant replay clips.
**Coach:** shot distribution charts, court heatmaps (player movement + bounce density),
strengths/weaknesses (e.g. backhand error rate, serve %), tactical suggestions, exportable
match report. Mobile-responsive; Grafana for deep stat exploration.
