> **TruthLens AI** — an Agentic AI system for **explainable misinformation
> detection**. It combines an interpretable ML classifier, retrieval-augmented
> fact-checking (RAG), and a multi-agent Generative-AI explanation layer, and
> runs **fully offline on a laptop** with no API key.

## ⚡ Run it in 3 commands

```bash
cd source_code
pip install -r requirements.txt
streamlit run app.py
```

The app auto-trains on first launch and opens at http://localhost:8501.
